# 📊 Insurance Claims & Fraud Risk Analysis Dashboard

## 📌 Project Overview
This project uses Microsoft Power BI to analyze insurance claims, identify fraud patterns, and explore fraud risk scores across different claim types, regions, and customer demographics.

The dashboard provides interactive visualizations to support data analysis and data-driven decision-making.

## 🎯 Project Objectives
- Analyze total insurance claims and claim amounts.
- Compare fraudulent and non-fraudulent claims.
- Identify claim patterns across regions and claim types.
- Analyze fraud risk scores across different categories.
- Understand claim status and premium amount trends.

## 📈 Dashboard Pages

### 1. Executive Dashboard
- Total Claims
- Fraud Claims
- Total Claim Amount
- Fraud vs. Non-Fraud Claims
- Claims by Claim Type
- Claim Amount by Claim Type
- Claims by Claim Status
- Fraud Claims by Claim Type
- Claims by Region
- Average Claim Amount by Region

### 2. Risk Analysis Dashboard
- Average Fraud Risk Score by Claim Type
- Average Fraud Risk Score by Region
- Average Fraud Risk Score by Gender
- Fraud Risk Score Distribution
- Average Claim Amount by Claim Status
- Average Claim Amount by Region
- Average Premium Amount by Claim Type
- Average Premium Amount by Region
- Average Premium Amount by Gender

## 🛠️ Tools & Technologies
- Microsoft Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)

## 🚀 How to Use
1. Clone or download this repository.
2. Open `Project_Dashboards.pbix` using Microsoft Power BI Desktop.
3. Configure the data source if prompted.
4. Explore the dashboard pages and visualizations.
5. Use available filters to analyze the data.
